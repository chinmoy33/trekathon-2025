This project includes the Host app for the travel package and homestay.

##Step 1
In order to access the Register page for the app go to the endpoint "api/v1/project/host/register".

##Step 2
After registration access the Login page for the app by going to the endpoint "api/v1/project/host/login".

##Functionalities that can be performed.
After login you will be redirected to the hostdashboard and will be able to perform the following activities:
>Add travel package.
>Add Homestay.
>View travel package and homestay.
>edit travel package and homestay.
>View my listings.
>Search for a package or homestay.
